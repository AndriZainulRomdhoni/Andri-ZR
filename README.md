# Andri-ZR
Nama : Andri Zainul Romdhoni
NIM : C2583207021
Kelas : PTI3B
Program Sistem Monitoring Stok dan Penjualan Kantin Kampus merupakan aplikasi berbasis console yang dibuat menggunakan bahasa pemrograman C. Program ini dirancang untuk membantu pengelola kantin dalam mengelola data produk, memantau ketersediaan stok barang, melakukan transaksi penjualan, serta mengetahui hasil penjualan setiap produk.
